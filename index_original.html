💡

Instructor Teaching Moment: How Jenkins Detects Success vs Failure

Direct student attention to the final line in the output: Finished: SUCCESS. Explain that Jenkins does not understand the content of human messages. Instead, Jenkins monitors the operating system exit code returned when the process finishes:

  • Exit Code 0: Signals clean completion without errors. Jenkins marks the build as SUCCESS (Blue Ball).
  • Non-zero Exit Code (e.g., 1, 127): Signals an error. Jenkins aborts subsequent steps and marks the build as FAILURE (Red Ball).

Instructor Teaching Moment: Enterprise Environment Variable Mechanics

Jenkins automatically converts every declared project parameter into an environment variable before launching the build process. Key takeaways for students:

  • OS Portability: On Windows, variables are accessed via %PARAM_NAME%. On Linux/Unix, via ${PARAM_NAME}. In Jenkinsfiles (Pipeline syntax), via params.PARAM_NAME or env.PARAM_NAME.
  • Security & Sanitization: In production pipelines, always sanitize user-supplied string parameters to prevent command injection vulnerabilities.
